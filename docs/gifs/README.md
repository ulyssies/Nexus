# Demo GIFs

Short screen recordings of the README-highlighted tabs, generated by
[`scripts/record-demos.mjs`](../../scripts/record-demos.mjs) (Playwright → ffmpeg).

These are **not** committed by default — generate them locally:

```bash
# one-time tooling (kept out of package.json deps so installs stay lean)
npm i -D playwright
npx playwright install chromium
# + ffmpeg on PATH  (macOS: brew install ffmpeg)

# with the frontend (5173) and backend (3001) both running:
npm run record:demos            # records home.gif, jobs.gif, graph.gif, research.gif
npm run record:demos -- home    # just one tab
```

Output lands here as `home.gif`, `jobs.gif`, `graph.gif`, `research.gif`. Edit the
per-tab `steps` in the script to change what each clip demonstrates. Once the GIFs
exist, swap the screenshot embeds in the main README for the matching GIF.
